# Suporte

## Onde pedir ajuda

| Preciso de | Onde |
| :--- | :--- |
| Entender como usar | [README](README.md) e a [documentação](https://github.com/pedroiff0/portfolio#readme) |
| Reportar um erro | [Nova issue](https://github.com/pedroiff0/portfolio/issues/new/choose), formulário "Relatar problema" |
| Sugerir uma melhoria | [Nova issue](https://github.com/pedroiff0/portfolio/issues/new/choose), formulário "Sugerir funcionalidade" |
| Relatar vulnerabilidade | [SECURITY.md](SECURITY.md) (nunca em issue pública) |

## Antes de abrir uma issue

1. Leia o README e as perguntas frequentes.
2. Pesquise nas [issues](https://github.com/pedroiff0/portfolio/issues) abertas e fechadas.
3. Reproduza com a versão mais recente.

## Prazos

Este é um projeto mantido por uma pessoa. As respostas costumam vir em alguns dias úteis, sem garantia de prazo.
