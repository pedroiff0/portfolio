# Guia de Contribuição — Portfolio

Agradecemos o interesse em sugerir melhorias no website do **Portfólio**!

---

## 1. Padrões de Código
- HTML5 semântico, CSS moderno e JavaScript vanilla modular em `src/`.
- Testes visuais e de interação via Playwright em `tests/`.
- Commits convencionais (`feat:`, `fix:`, `style:`, `docs:`).

---

## 2. Testes Locais
```bash
make dev
make lint
```
