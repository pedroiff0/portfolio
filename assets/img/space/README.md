## Usage

Applied as the site-wide fixed background (`.milky-way-bg` in `assets/css/style.css`,
behind `#cosmosCanvas`) — the same photographic backdrop shows through on the hub and
every sector, with the procedural starfield/galaxy canvas layered on top for parallax
and interactivity.
